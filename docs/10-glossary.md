# 譯名表

一代已有中文說明書（軟體世界貴族版第 068 號），本作沒有找到當年的中文說明書，
所以譯名分三級處理：

1. **一代出現過的角色**：沿用[一代譯名表](https://github.com/wicanr2/maniac_mansion_cht/blob/main/docs/10-glossary.md)。
2. **真實歷史人物**：用通行的中文譯名。
3. **本作新角色**：自訂，理由記在下面。

遊戲名採當年《遊戲獵人》雜誌（松崗）評測所用的**《瘋狂大樓 II — 瘋狂時代》**。

### 為什麼觸手不沿用一代譯名

一代說明書把 Purple Tentacle 譯作「紫色怪物」、Green Tentacle 譯作「大食怪」，
那是為「擋路的怪物」這個角色定位取的。本作牠們是有人格、有台詞的主角級角色——
紫色觸手是野心家，綠色觸手是溫和的音樂愛好者——沿用「大食怪」會嚴重失準。

本作改用**紫色觸手／綠色觸手**：`Tentacle` 在本作既是種族也是名字，遊戲標題
《Day of the Tentacle》本身就靠這個字，直譯保留了那層雙關。

## 十個指令（verb）

指令列是 3 列 × 3 欄，另加句子列的「走到」。中文標籤已實機驗證排版無誤：

| 原文 | 中譯 |
|---|---|
| Walk to | 走到 |
| Give | 給予 |
| Open | 打開 |
| Close | 關上 |
| Pick up | 拿起 |
| Look at | 查看 |
| Talk to | 交談 |
| Use | 使用 |
| Push | 推 |
| Pull | 拉 |

介系詞（組句用）：`in` → 放進、`with` → 用、`on` → 在、`to` → 給。

> 原文的 `L\xb0k at` 與 `Pu\xb8` 用了 `0xB0`＝“oo”、`0xB8`＝“ll” 兩個自製合字，
> 都落在 CJK 碼空間內。翻成中文之後自然消失，但**譯文裡不可以再出現任何
> 0xA1–0xFD 範圍的單一 latin-1 位元組**。
