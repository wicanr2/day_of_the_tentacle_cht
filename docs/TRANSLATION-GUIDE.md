# 翻譯規範

譯名一律以 [`10-glossary.md`](10-glossary.md) 為準；格式與文風以此檔為準。
批次檔在 `translations/dott/`（37 批）與 `translations/maniac-v1/`（8 批），
每行 `原文<TAB>譯文`，**只填第二欄**。

## 格式鐵律

1. **一行一句，不增不刪不換序。** 批次檔的行數固定。
2. **譯文欄留空 = 沿用原文。** 不確定就留空，不要亂填。
3. **`\ddd` 原樣保留於原位置。** 三位十進位的 escape 是控制碼，不是文字：
   - `\255\003` 換頁／等待
   - `\255\004\xxx\xxx` 嵌入數字（前後中文要讀得通）
   - `\255\001` 換行
   句首的語音前綴（四組 `\255\010`，共 16 bytes）**不會出現在批次檔裡**，
   工具已經先切掉、回填時原樣接回，不必理會。
4. **`^` 是控制符，原樣保留。** 在本作它顯示成省略號／停頓，位置不要動。
5. **`@` 是排版填充**，出現在物件名尾端時保留。
6. **譯文不可含 0xA1–0xFD 範圍的單一 latin-1 位元組**：`·`、`é`、`ë`… 都會被引擎
   當成雙位元組首碼而讓整段錯位。人名間隔號用 `・`（U+30FB）。
7. **標點用全形**：「」，。！？…… 破折號用 ——。不用半形雙引號。

## 文風

本作是卡通化的黑色喜劇，語氣要玩得起來，但**不塞當代流行語、網路梗、注音文**——
這是 1993 年的遊戲，年代感要留住。

三個時代的語域要分得開：

- **兩百年前（1789）**：開國元勳講話文謅謅、拿腔拿調，但不要變成文言文。
- **現在**：高中生口語，短句。
- **兩百年後**：觸手統治人類的世界，語氣浮誇、官腔、帶點荒謬的正經。

角色：

- **伯納**：神經質的書呆子，容易緊張，講話囉嗦但有條理。
- **拉玟**：直來直往，帶點瘋，對噁心的東西反而很興奮（醫學院學生）。
- **霍基**：憨厚、反應慢半拍，重金屬樂迷的用語。
- **紫色觸手**：自大狂，語氣誇張，動不動就宣布要統治世界。
- **綠色觸手**：溫和有禮，愛音樂，跟紫色觸手完全相反。
- **佛瑞德博士**：瘋狂科學家，激動、愛咆哮。

## 長度

- 配音台詞的字幕停留時間跟語音長度綁在一起，**譯文盡量不超過原文的視覺長度**。
- 對白區一行約 26 個中文字（16×14 字模、邏輯寬 8）；長句引擎會自動折行，
  但太長仍會影響閱讀節奏。
- **物件名（OBNA）要短**，句子列要放得下「指令 ＋ 物件名」，建議 ≤ 8 個中文字。

## 不翻的東西

- 版本字串、`Heap Status` 之類的除錯訊息（工具已自動排除大部分）。
- 純數字、純符號的行。
- 遊戲內的**英文招牌美術**（那是圖，不是文字）。

## 檢查

翻完一批跑：

```bash
python3 tools/check_translation.py translations/dott/b001.tsv
```

會檢查：escape 是否成對保留、有無非法的 latin-1 高位元組、行數、TAB 欄位數。
