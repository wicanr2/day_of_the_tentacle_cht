# 推廣片

75.6 秒、1280×720。全程 docker，不開剪輯軟體，`tools/promo/` 的腳本可以重跑。

素材真實性是硬條件：**配樂是從遊戲本身錄下來的原版 MT-32 音樂，畫面是實機錄影**，
沒有一個像素或一個音符是合成頂替的。

## theme：螢光綠與夜空紫

色票不是憑喜好挑的，是從實機畫格量出來的：

```
convert 畫格.png -resize 120x120 -colors 10 -depth 8 -format %c histogram:info:- | sort -rn
```

| token | 值 | 來源 |
|---|---|---|
| `BG_DEEP` | `#05050D` | 片尾星空最暗處 |
| `BG_LITE` | `#292884` | 星空主色 |
| `ACCENT` | `#49F571` | 標題 logo 的螢光綠 |
| `ACCENT_DK` | `#2A8C42` | 同上的暗部，做浮雕陰影 |
| `ACCENT2` | `#9B3EBB` | logo 的洋紅紫，也是紫色觸手的紫 |

字體用 Noto Sans CJK Bold。上位規則說「黑體＝手遊味」是針對西方奇幻；
1993 年的卡通式黑色喜劇用襯線反而過於正經。

中文字另外做了三件事湊出俏皮感（`zh()`）：**字級放大**（標題 100、對白 84、
字幕 38）、**螢光綠描邊**、**±2 度微幅旋轉**。描邊要分兩層畫——先畫粗描邊那張，
再把無描邊的疊上去，筆畫內部才不會被描邊侵蝕。旋轉要獨立成透明層再合成，
`-annotate` 的角度參數是切變不是旋轉。

## 敘事骨架：對白精選輯

本作靠台詞吃飯，所以主結構是「實機片段 ↔ 大引號對白卡」交替，快切（4–5 秒一張）。

| # | 型 | 內容 | 秒 |
|---|---|---|---|
| 1 | 標題卡 | 瘋狂時代 / Day of the Tentacle | 5.0 |
| 2 | 實機 | 紫色觸手喝廢水（開場 30–39 秒） | 9.0 |
| 3 | 對白卡 | 「看起來對身體不太好。」— 綠色觸手 | 4.2 |
| 4 | 實機 | 紫色觸手長出手臂 | 8.0 |
| 5 | 對白卡 | 「更聰明！更有侵略性！」— 紫色觸手 | 4.2 |
| 6 | 實機 | 佛瑞德博士 | 8.0 |
| 7 | 數據卡 | 4,239 句台詞 | 4.0 |
| 8 | 實機截圖 | Ctrl+T 的 OSD | 4.5 |
| 9–11 | 三格卡 | 同一句的三個語音版本，依序高亮並播放 | 9.1 |
| 12–14 | 實機截圖 | 泰德的電腦 → 一代選角 → 一代指令列 | 13.5 |
| 15 | 結尾卡 | repo 與授權 | 6.0 |

分鏡總長由 `add()` 累加成 `TOTAL`，語音段的插入點直接讀它——手算會隨改秒數失準。

## 踩到的雷

### 容器裡沒有音效卡 → 過場永遠卡住

第一次錄開場，畫面在「紫色觸手喝廢水」那一格停了 165 秒不動。log 被 ALSA 的
`open /dev/snd/seq failed` 洗版。

原因不是語音包也不是引擎：**容器沒有音效裝置，SDL 開 ALSA 失敗，mixer 不前進，
而靠語音計時的過場在等一個永遠不會結束的聲音**。用英文原音跑一次得到完全一樣的
結果——這個正對照排除了「中文語音包有問題」。

解法是 `SDL_AUDIODRIVER=dummy`：dummy 驅動會以即時速率消耗緩衝，過場就照原本節奏走。
（要錄音訊則用 `disk`，它比即時快，所以錄完要掃整段找有聲窗，不能假設音樂在前 N 秒。）

### `alimiter` 預設會把輸出補回滿刻度

成片峰值一直卡在 −0.0 dB。把 `limit` 從 0.95 調到 0.80，**平均音量反而變大**
（−15.8 → −14.8 dB）。

`alimiter` 的 `level` 選項預設 `true`，意思是「限完之後自動補回滿刻度」——
調低 limit 等於壓得更狠再補得更多。要留 headroom 必須同時關掉它：
`alimiter=limit=0.89:level=false`，這才拿到 max −1.0 dB。

### 畫面置中往上推會切掉字幕

SCUMM 的角色台詞畫在**畫面上緣**。把 640×400 的實機畫面放大到 1126×706 再
`overlay=(H-h)/2-24` 置中偏上，上緣就跑到 −17，字幕整條被切掉。
截圖類的版面要留字幕條，作法是先把畫面等比縮進固定框（1024×640）再補底，
畫框自然落在字幕條之上。

### MT-32 要確認「真的有出聲」，不能看沒報錯就算數

`--enable-mt32emu` 只是把模擬器編進 binary（三支 binary 都有 `USE_MT32EMU = 1`）；
要真出聲還要 ROM，檔名須為 `MT32_CONTROL.ROM` / `MT32_PCM.ROM`，並用
`--extrapath` 指到 ROM 目錄。ROM 缺了或名字不對，ScummVM 會**安靜地退回 AdLib**。

判斷有沒有真的走 MT-32，最省事的技術訊號是**左右聲道差值**：

| | 左右差 RMS | 頻譜重心 |
|---|---|---|
| AdLib（OPL2，本來就是單聲道） | 0 | 4,321 Hz |
| MT-32（有聲相） | 3,416 | 1,800 Hz |

差值 0 就是沒走到 MT-32。頻譜重心也對得上聽感——AdLib 的 FM 方波把能量推到高頻，
MT-32 的取樣音色明顯溫厚。

MT-32 的輸出音量比 AdLib 小得多（同一段 RMS 748 vs 2,363），`loudnorm` 目標要調高
（本片用 `I=-16`）。

**ROM 一律不入 repo，也不進散布包**（`.gitignore` 已擋 `*.ROM`）。本機放在
`~/cht/mt32`，用的是 `MT32_CONTROL.1987-10-07.v1.07.ROM` 與 `MT32_PCM.ROM`。

### 不用 zoompan

`-loop 1 -t S` 加前置 `fps` 會讓 zoompan 算成 `(FPS*S)²` 幀。靜態圖 + fade
對推廣片完全夠看，而且秒成。

## 散布界線

| 產物 | 位置 | 為什麼 |
|---|---|---|
| `dott-cht-promo.mp4` | 本機 `dist-all/` | 含原版配樂與遊戲影像 |

| 擷取的原始素材（`intro-*.mp4`、`music.raw`、`bgm.wav`） | 本機暫存 | 原版音訊與影像 |

MT-32 ROM 是 Roland 的著作，`.gitignore` 已擋 `*.ROM`，也不進任何散布包。

**成片要公開上傳前先確認授權**：配樂是原版遊戲音樂（作曲家 Peter McConnell、
Michael Land、Clint Bajakian 的著作），影像是 LucasArts 的美術。用原版素材是為了
品質真實，但那跟「能不能對外散布」是兩回事。
